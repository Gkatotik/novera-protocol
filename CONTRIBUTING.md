# Contributing

Thank you for your interest in Novera Protocol.

## Scope of this repository

This is a curated public information repository. It is not the private production engineering repository and does not accept unrequested implementation work, smart contracts, or operational configuration.

## Before proposing a change

1. Review the repository boundaries in the [README](README.md).
2. Read the [public status model](docs/product/status-model.md) and [website and documentation alignment guide](docs/product/website-and-docs-alignment.md).
3. Confirm product, network, integration, token, and roadmap language against the linked public evidence.
4. Do not include confidential information, credentials, customer data, legal documents, identity documents, payment data, private keys, or other sensitive material.
5. Keep each change narrow enough to review for technical, security, legal, compliance, and brand accuracy.

## Public feedback

Public Issues are intentionally disabled so investor- and ecosystem-facing materials remain accurate, reviewed, and appropriately scoped. Use the website's [discussion path](https://noveraprotocol.org/contact) for non-sensitive product or documentation feedback. Follow [SECURITY.md](SECURITY.md) for security-sensitive matters.

## Pull requests

If a maintainer has invited a documentation contribution:

- use a feature branch;
- explain the purpose and evidence for each claim change;
- use the controlled public status vocabulary;
- distinguish current MVP, mock, planned, evaluated, conditional, and excluded functionality;
- confirm links, headings, Markdown formatting, and sensitive-data checks before requesting review.
