# Security Policy

## Scope

This public repository contains investor-facing documentation only. It does not contain a production service, smart contracts, wallets, credentials, or active endpoints.

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities, sensitive design concerns, credentials, or personal data. Send a concise report to [gkatotik@noveralabs.io](mailto:gkatotik@noveralabs.io) with the subject `Novera security report`.

Please include:

- A concise description of the concern
- Affected public document or repository path
- Reproduction or evidence where appropriate
- Potential impact
- Suggested remediation, if known

Do not attach credentials, private keys, identity documents, payment data, customer data, confidential legal records, or live exploit payloads.

## Safe-harbor boundary

Do not attempt to access accounts, infrastructure, private repositories, third-party systems, or unpublished services. Do not test against systems without explicit written authorization.
